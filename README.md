# Sabah Industrial Group

Premium bilingual corporate website for Sabah Industrial Group, available in Persian and English.

## Live preview

- [English](https://moazzamitr-bit.github.io/sabahholding/en)
- [فارسی](https://moazzamitr-bit.github.io/sabahholding/fa)

## Highlights

- Responsive Persian and English experiences
- Executive industrial visual direction
- Company, product, leadership, news, media, and contact pages
- Local Vazir font assets for the Persian interface
- Interactive hero stories and an Iran operations map

## Local development

Requires Node.js `22.13.0` or newer.

```bash
npm install
npm run dev
```

Run the production build and automated checks with:

```bash
npm test
```

The project uses React, Next.js-compatible routing, vinext, and Cloudflare-compatible output.
